# 10-08 开盘现场核对步骤

> 国庆后第一个交易日 2026-10-08。kansoku 的 A 股盘中实时（当天分钟线、3 秒快照拼 K 线）至今没在交易时段跑过，这份清单就是第一次实战核对。
> 已经用 09-30 的真实快照回放钉住的逻辑（`packages/core/test/ricequantReplay.test.ts`）：竞价不开 K 线、第一根开盘价 = 09:25 撮合价、午休不出 K 线、15:00 后定格、全天量对得上日线、北京时间横轴。现场要核对的是"回放测不到"的部分：米筐盘中真实返回什么、App 端到端显示对不对。

## 总原则：今天同花顺仍是主力

- **同花顺照常开着看盘，kansoku 并排对照。** kansoku 任何一项不通过，都只是记录，不影响看盘。
- 全天核对都通过之前，不要凭 kansoku 的数下单。
- 核对只读：不碰 StockSeller 的 FIFO/下单/配置接口，实盘看板只读 `/api/snapshot`。

## 开盘前准备（10-07 晚上或 10-08 09:00 前）

1. 拉最新分支：`git pull fork feat/ricequant-cn`（或在本机直接用当前工作区）。
2. 投射 Pro 叠加层：`pnpm overlay:sync`。
3. 带录盘启动桌面版（三只票：一只沪市主板、一只深市、一只科创板/创业板，可换成自己的票）：

   ```bash
   KANSOKU_RQ_RECORD_SYMBOLS=600519.SH,000001.SZ,688330.SH pnpm dev:desktop
   ```

   录盘写到 `~/.cache/kansoku/rq-record/snapshots-2026-10-08.jsonl`，一只票一天约 2 MB。
4. 另开一个终端，准备随时跑核对小工具（不开 App 也能用，只读）：

   ```bash
   pnpm --filter @kansoku/core live-check
   ```

   一条命令跑完（默认观察 20 秒，可写 `live-check 30` 改成 30 秒），最后打出一张「通过 / 失败 / 提示 / 跳过」表，有失败时退出码是 1。它按当前北京时间自动决定查哪些项：
   - 任何时候：米筐桥连通、交易日历、额度已用、轮询间隔、快照覆盖自选（列出缺哪几只）、首轮快照耗时、运行中报错、涨跌停价（个股有、指数没有）；
   - 09:15 前：额度是否已按天重置（< 1%）；
   - 09:15–09:25：竞价显示（现价 = 买一 = 卖一）、竞价不开 K 线；
   - 09:25 之后：第一根 K 线开盘 = 快照开盘价、当天 1 分钟线、当天日 K、分时图（不是 partial）；
   - 连续竞价：报价新鲜（≤ 15 秒）、五档盘口满 5 档；
   - 11:30 之后：午休无假 K 线；15:00 之后：收盘定格（最后一根 14:55，收盘 = 现价）。

   样本固定用 600519.SH（成交最活跃，不在自选里也会临时加进来）。判定标准写在 `packages/core/src/marketdata/liveCheck.ts`，有测试。下面各时段表里"跑 `live_check.ts`"都指这条命令；表里需要人眼对照同花顺的项（价格是否一致、图长得对不对）工具查不了，仍要手看。

## 失败了怎么办（都不影响用同花顺看盘）

| 现象 | 先做什么 | 再不行 |
| --- | --- | --- |
| 报价不动 / 日志反复 `snapshot poll failed` | 看日志里的错误；重启 App（桥会重新拉起，冷启动约 5 秒、约 2.5 MB 流量） | 记下时间和错误原文，今天 A 股只看同花顺 |
| 日志 `[rq-bridge] restarting` 反复出现 | 说明米筐请求卡住被自动重启；记下频率 | 同上 |
| 第一根 K 线被昨收拉出长下影线 | 截图，记下代码和时间；这是今天修过的问题，不该再出现 | 回放断言会抓到，收盘后跑一遍上面的回放 |
| 午休出现 K 线、或 15:00 后 K 线还在动 | 截图记录 | 同上 |
| 当天 1 分钟线 / 日 K 没有今天 | 只记录，不影响 5/15/60 分钟 | 这是 license 能力问题，要跟米筐确认或换取数方式（需要 Barney 决定） |
| 流量档位升到 caution 以上 | `live_check.ts` 看已用量；检查是不是别的程序（MDD）在用同一个 key | 档位升高后程序会自己放慢，不用手动处理；升到 stop 时报价 60 秒一轮 |
| 盘口 / 分时 / 自选表显示不对 | 截图记录；这三样都只读行情，不影响别的页面 | 分时可点 K 线周期切回；自选表点「名称」表头回到自选顺序 |
| 需要退回修之前的版本 | `git log --oneline` 找到对应提交，用 `git revert <提交>` 单独撤销 | 相关提交：`b3f13bd4`（竞价/定格）、`bf15f719`（流量保护/日历/录盘）、`30393ad8`（均价线/缓存）、`789f6cdf`（首页午休布局）、`5d335c67`（盘口/涨跌停）、`de778151`（分时图）、`69bf1ec3`（自选表）、`f4be868b`（K 线均价线口径） |
