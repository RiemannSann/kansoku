# kansoku 看 A 股：使用说明

> 写给 Barney，2026-10-07（国庆假期最后一天）。分支 `feat/ricequant-cn`，只在 fork 上。
> A 股行情走米筐（RiceQuant），美股、港股还是走长桥。实盘持仓只读 StockSeller 看板，kansoku 不会下单，也不会改任何交易配置。

## 一、怎么启动

本机已经配好，正常只要两条命令：

```bash
cd ~/Projects/kansoku
pnpm overlay:sync # 没有 Pro 目录时会提示"OSS workspace unchanged"，正常
pnpm dev:desktop  # 起桌面版（Electron），不用另外起服务端
```

配置在两个地方，**仓库根目录 `.env` 里的同名项优先**，两边现在写的是一样的：

| 配置项                                       | 作用                                                                    |
| -------------------------------------------- | ----------------------------------------------------------------------- |
| `MARKET_PROVIDER_CN=ricequant`               | A 股走米筐；删掉或注释掉就回到长桥                                      |
| `RQ_PYTHON`                                  | 装了 `rqdatac` 的 Python（`~/.local/share/kansoku-rq/venv/bin/python`） |
| `RQ_LICENSE_FILE`                            | 米筐 license 文件路径（内容不要贴到任何地方）                           |
| `STOCKSELLER_LIVE_URL=http://127.0.0.1:8766` | 设了才把实盘持仓并进首页和个股页                                        |

想看实盘持仓，另开一个终端先起 StockSeller 的只读网页看板（和终端里的 `bs` 用同一套数据，可以同时开）：

```bash
cd ~/Projects/python/scripts/local_code && uv run --project .. python StockSeller/live_view_web.py --os --os3 --no-open
```

看板没开也没关系：首页当作没有实盘仓位，个股页「环境」里提示"实盘看板没开"，其它功能不受影响。

**要录盘（开盘第一天建议录）**：启动时带上要录的票，米筐每轮快照原样写到 `~/.cache/kansoku/rq-record/`，事后可以拿来回放查问题，一只票一天约 2 MB：

```bash
KANSOKU_RQ_RECORD_SYMBOLS=600519.SH,000001.SZ,688330.SH pnpm dev:desktop
```

## 二、界面在哪

- **首页顶上的指数条**：上证、深成、创业板、科创50、沪深300、中证500、中证1000，带点位和涨跌。窗口宽度不到 1500 时会折成两行。
- **首页「A 股自选」表**：点表头排序（涨跌幅、成交额、成交量（手）、行业）；「行业」列是这只票所属的申万二级行业当天涨跌，后面跟涨停家数。
- **首页「申万行业」**：31 个一级行业按涨跌幅排，也能按涨停数、成交额、上涨占比排；点一行展开二级行业和成员股。
- **代码直达**：首页输入框直接敲 6 位代码回车就行（`600487`、`300750`）。注意 `000001` 当成平安银行；要看上证指数写 `000001.SH`。北交所的票还不支持。
- **个股页**：
  - 周期按钮最前面是「分时」；切到日 / 周 / 月线时右边出现「前复权 / 不复权 / 后复权」，会记住你的选择。
  - 右侧第一个 tab「盘口」：五档买卖、涨停跌停价、今开昨收、成交量额，下面是所属申万一级 / 二级行业当天的涨跌和涨跌家数。
  - 「环境」tab 里有「实盘（StockSeller）」一栏：今日买入 / 可卖 / 清仓中各多少股、均价、盈亏。看板开了精简模式（`--compact`）时没有分服务器的股数，这里会显示「约 N 股」（用成交额 ÷ 价格倒推的）。

## 三、明天（10-08）开盘先看什么

**同花顺照常开着做主力，kansoku 并排对照。全天核对通过之前，不要凭 kansoku 的数下单。**

完整的逐时段核对表在 [10-08 开盘现场核对步骤](./2026-10-08-live-checklist.md)。时间紧的话，按下面的顺序看：

1. **09:10**：另开终端跑 `pnpm --filter @kansoku/core live-check`，看最后那张表：交易日 = true，额度已用 < 1%（说明按天重置了），没有"失败"。
2. **09:15–09:25 集合竞价**：自选表和个股页「盘口」标"集合竞价"，价格和同花顺的竞价价一致；5 分钟 K 线这时**不应该**出现今天的第一根。
3. **09:25 撮合后**：现价 = 同花顺开盘价，分毫不差。
4. **09:30 之后**：挑 3 只票，报价、五档盘口和同花顺最多差一轮快照（3 秒）；打开「分时」看有没有今天的走势、均价线和同花顺的黄线差不多。
5. **10:00 前后**：首页「申万行业」排行有没有跟着动（1 分钟刷新一次），涨停家数和同花顺对得上大致数量。
6. **StockSeller 看板开着时**：随便点一只今天买了的票，「环境」里的股数、均价和看板一致。

每项看到的值和时间记在核对表里，不通过只记录，不影响看盘。

## 四、哪些功能是明天盘中才第一次真正验证

下面这些都写了测试、在休市日用 09-30 的真实数据或 StockSeller 自己生成的样本测过，但**还没在真正开盘时跑过**：

| 功能                    | 休市日已经验证了什么                                                            | 盘中才知道的                                                                                                                    |
| ----------------------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 3 秒报价、集合竞价价格  | 用 09-30 录下的真实快照回放，竞价不开 K 线、第一根开盘价对                      | 米筐盘中快照是不是真的 3 秒一刷、竞价时买一 = 卖一                                                                              |
| 当天 1 分钟线、当天日 K | 休市日只能拿到 09-30 的                                                         | **最大的未知**：这个米筐 license 盘中能不能拿到当天的分钟线。拿不到时分时图会提示"当天分钟线没取到"，只能从打开页面那一刻开始拼 |
| 分时图、均价线          | 用 09-30 数据画出来和同花顺一致                                                 | 盘中每分钟重拉 + 3 秒快照接上当前这一分钟，接缝处对不对                                                                         |
| 五档盘口                | 休市日显示的是 09-30 收盘那一刻                                                 | 盘中跟着快照刷新的速度                                                                                                          |
| 申万行业排行、行业列    | 休市日用 09-30 收盘数据算的，实测每次约 0.8 MB                                  | 盘中 1 分钟刷新一次的流量和速度                                                                                                 |
| 实盘持仓（StockSeller） | 用 StockSeller 自己的代码生成的三种样本（完整、竞价时多两列、精简模式）测过解析 | **还没连过真看板**；看板盘中的真实数据能不能正确对上                                                                            |
| 流量保护四档降级        | 集成测试按档位数过每个频道发出的请求                                            | 真实用量是否和估算一致（估算正常看盘一天 2%–4%）；MDD 用同一个 key 时会不会把我们挤到降级                                       |

流量四档降级时页面会怎样（详见 [流量实测与保护](./quota.md)）：

| 档位（今日已用） | 报价、盘口 | 分时       | 申万行业         |
| ---------------- | ---------- | ---------- | ---------------- |
| 正常（< 50%）    | 3 秒一轮   | 每分钟重拉 | 1 分钟刷新       |
| 注意（≥ 50%）    | 6 秒一轮   | 每分钟重拉 | 2 分钟刷新       |
| 节省（≥ 75%）    | 15 秒一轮  | 每分钟重拉 | 停，显示最后一份 |
| 停止（≥ 90%）    | 60 秒一轮  | 每分钟重拉 | 停，显示最后一份 |

自选很多时一轮快照有只数上限（400 / 300 / 200 / 100），超出的轮流刷新，但开着图的那只每轮都在。到了"节省""停止"档，报价已经明显比同花顺慢，这时就以同花顺为准。

## 五、遇到问题怎么退回同花顺

kansoku 只读，不下单、不碰 StockSeller 的 FIFO / 下单 / 配置接口。**任何时候直接关掉 kansoku、只看同花顺，都不会影响交易。**

| 情况                                                       | 怎么办                                                                                                                                                                       |
| ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 价格对不上、刷新慢、某个功能不对                           | 以同花顺为准继续看盘；在核对表里记下时间、票、两边的数，收盘后再查                                                                                                           |
| 桌面版打开是黑底白字"startup failed"                       | 开发模式偶尔会抢在打包完成前启动。终端里 Ctrl+C，再跑一次 `pnpm dev:desktop`                                                                                                 |
| 首页 A 股全是"--"、终端反复出现 `snapshot poll failed`     | 米筐桥连不上或额度出问题。跑 `pnpm --filter @kansoku/core live-check` 看是哪一项失败；先回同花顺                                                                             |
| 米筐整天不可用，但还想用 kansoku 看图                      | 把仓库 `.env` 和 `~/.config/kansoku/kansoku.env` 里的 `MARKET_PROVIDER_CN=ricequant` 都注释掉再重启，A 股回到长桥：能看报价和 K 线，但没有盘口、分时、申万行业、集合竞价价格 |
| 申万行业提示"米筐今日流量已用 …，暂停「market_snapshot」…" | 米筐额度已用超过 75%，自动停了这项，报价和 K 线还在。不用处理                                                                                                                |
| 实盘持仓提示"实盘看板没开"                                 | StockSeller 看板没开或端口不对；按第一节的命令起看板。持仓以 `bs` / 看板为准                                                                                                 |
| 想彻底回到没有这批改动的 kansoku                           | `git switch main`（这批改动都只在 `feat/ricequant-cn` 上）                                                                                                                   |
