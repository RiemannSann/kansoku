# 预告短片：一镜到底 + 卡点爆发

日期：2026-09-26。在 `apps/video/` 里新做第四支片子，和产品介绍片、v0.43 新功能片、MU 财报周完整片并存，已有三支不动。

## 目标

- 给 X / 社交时间线用的 36 秒预告：16:9、1920×1080、30fps，静音自动播放也能看懂，前 2 秒必须抓人。
- 旧片都是讲清楚功能的叙事片，这支反过来：少讲道理，拼节奏和镜头。
- 创意方向：从一根 K 线的特写开始一镜拉远，中段音乐落下后 8 个功能卡点连闪，最后所有画面坍缩回一根 K 线、变成 logo，首尾闭环。

## 节奏骨架

- 120 BPM，一拍 0.5 秒 = 15 帧，每个切点都落在整帧上。
- 全片 72 拍 = 36 秒。
- 代码里时间一律用拍写（`beats(2.5)`），不写秒，避免累积误差。

### 故意打破的旧规矩

旧片规定主句至少停 2.5 秒。DROP 段每个功能只有 1–1.5 秒，所以那里只放两个字加一行小字，不放完整句子；完整句子只出现在开头和结尾，都停 3 秒。

其余红线照旧：不出现真实持仓、账户金额、AI 费用、API key、个人路径；不承诺收益，不说「自动交易」。所有截图复用完整片已经审过的素材，情景概率只用真实分析里的数字。

## 代码

一镜到底需要镜头在同一个世界里连续移动，不能沿用旧片「每段一个场景、段段交接」的写法。分两层：

- **世界层**：一个大容器当摄像机（位置、缩放、旋转），K 线图、App 窗口、8 张卡都放在里面。钩子 → 拉远 → 卡墙 → 坍缩全靠移动摄像机，中间不切。
- **覆盖层**：DROP 的 8 个全屏画面、闪白、大字，盖在世界层上面。

| 文件                                                   | 内容                                                                                   |
| ------------------------------------------------------ | -------------------------------------------------------------------------------------- |
| `src/teaser.tsx`                                       | 主时间线，按拍子调度各段                                                               |
| `src/teaser/world.tsx`                                 | 摄像机和卡墙。卡墙的立体感靠每张卡一个深度值，按离镜头远近实时算位置和缩放，不引入 3D 库 |
| `src/teaser/candles.tsx`                               | 用真实 MU 日线画 K 线                                                                  |
| `src/teaser/mu-daily.ts`                               | MU.US 最近约 250 根真实日线，用 `longbridge kline` 拉取后导出（演示环境里现成的 `mu-earnings-week.daily.json` 只有 70 根，拉远时不够壮观） |
| `src/teaser/hook.tsx` `wall.tsx` `drop.tsx` `collapse.tsx` `end.tsx` | 各段动画，每个文件不超过 300 行                                    |

- 复用 `components.tsx`（配色、字体）、`motion.tsx`（逐字升起）、`full/data.ts`（SEPA 八条、AMD 训练数据）；情景概率 50 / 30 / 20 抄自 `full/scenarios.tsx` 里的真实分析结果；结尾借用 `full/end.tsx` 的射线和解码字思路。
- 避开已知的 Revideo 坑：带阴影或滤镜的节点不当容器用；逐字排版不用 `layout`，用 `measureText` 手动排。
- `render.ts` 加 `teaser` 目标，输出 `output/kansoku-teaser.mp4`，结尾音乐 1.2 秒淡出。视频包加 `start:teaser`，根目录加 `video:render:teaser`。

## 音乐

`scripts/bgm.mjs` 里合成器零件和完整片的谱子写在一起，拆成：

- `scripts/synth.mjs`：合成器零件（底鼓、镲、拍手、贝斯、铺底、拨弦、上升音效、冲击音效、混音和写 mp3）。
- `scripts/bgm.mjs`：完整片的谱子，改成引用零件。改前改后生成的 wav 逐字节一致（对比 md5）。
- `scripts/bgm-teaser.mjs`：新谱子，输出 `public/audio/teaser-bgm.mp3`。
  - 0–10s：低频嗡鸣 + 秒针般的镲，1.5s「别猜。」处一记冲击。
  - 10–13.5s：上升音效，镲越来越密。
  - 13.5–14s：整拍静音。
  - 14–26s：四拍子底鼓 + 贝斯，每个功能切点一记冲击，连闪段改成半拍一记。
  - 26–29s：坍缩一记大冲击。
  - 29–36s：和弦收住，拨弦琶音。

## 验收标准

1. 时长 36 秒 ±0.5；ffprobe 确认 1920×1080 / 30fps / H.264 / AAC 双声道，结尾音乐淡出。
2. 每个切点和音乐冲击对齐到帧：两边都从同一份拍号表取时间，误差不超过 1 帧。
3. 抽帧检查 1.5s、7s、12s、DROP 每张的中点、33s：字不重叠、不截断；DROP 每屏只有大字加一行小字。
4. 画面里没有真实持仓、账户金额、AI 费用、API key、个人路径。
5. `pnpm --filter @kansoku/video typecheck` 通过；原来三支片的代码不动，完整片 BGM 的 wav 逐字节不变。

## 实现记录

- Revideo 把时间按 1/30 秒浮点累加，切点刚好落在帧边界时会晚一帧。视频里的时间统一用 `cueTime()`（比精确值早 0.1 毫秒）换算。
- Revideo 合成的音轨比画面早 1 帧（33 毫秒，和原始 BGM 做互相关测出来的）。`render.ts` 给预告片加了 `audioDelayMs`，在结尾淡出那一步一起补上；其它片子不受影响。
- 验收时 17 个切点（DROP 8 个、连闪 8 个、坍缩 1 个）逐帧亮度检查全部落在拍号表那一帧，音轨偏移 0 毫秒。
