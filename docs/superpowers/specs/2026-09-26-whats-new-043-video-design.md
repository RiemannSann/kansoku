## 实现

- 新文件 `apps/video/src/whats-new.tsx`：一个 `makeScene2D` 场景，结构照抄 `project.tsx`（截图 `Img` + `Label` + `Pill` + 结尾品牌卡）。
- `Label` / `Pill` / `Corner` 和颜色常量 `C` 从 `project.tsx` 抽到 `apps/video/src/components.tsx`，两支片子一起用；`project.tsx` 只改 import，画面不变。
- `render.ts` 从命令行参数读选哪支：不带参数还是渲染旧片 `kansoku-product-intro.mp4`；带 `whats-new` 时渲染 `src/whats-new.tsx`，输出 `output/kansoku-whats-new-0.43.mp4`。
- 根目录 `package.json` 加 `video:render:new` 脚本。
- 画框底部加一条从透明到背景色的渐变遮罩，Pill 放在遮罩上。截图推移时滑到底部的 App 文字会先淡出，不会被 Pill 压住。
- 配乐 86 秒，片子约 54 秒。`render.ts` 渲染完用 `ffmpeg` 给新片结尾加 1.2 秒音频淡出（Revideo 的 `Audio.volume` 不能做渐变），旧片不受影响。
- 品牌卡主句写成「v0.43 · 现在更新」，上面已经有 KANSOKU 字标，不再重复写 Kansoku。

## 动效（2026-09-26 改版，科技产品感）

第一版只有淡入、慢推、淡出，被评「太普通」。改版后每段都有一个主角瞬间：

- 文字：标题逐字从遮罩里升起（`motion.tsx` 的 `RevealText` + `rise` / `sink`）。字宽用 canvas `measureText` 量出来再手动排位置，不用 Revideo 的自动排版：`layout` 容器里的 `layout={false}` 子节点动画不生效。
- 钩子：「画、搜、记住」几个字升起后依次变黄。
- 转场：旧标题沉下去，新画面由一道黄色光条从左往右擦出（`wipe`），Pill 依次弹出（`popIn`）。
- 镜头引导（二次改版，替换匀速平移）：每段先展示整张截图的全貌，再用聚光灯压暗四周、画出一圈发光描边框圈住第一个重点，镜头用 0.9 秒的快进快停推进过去（移动中带运动模糊）；然后描边框变形跳到第二个重点，镜头同步跟过去（`camera.tsx`）。聚光灯用洞口四周的 4 块暗色矩形拼出来，不用 `destination-out` 混合模式。
- Revideo 的坑：带阴影或滤镜的节点走缓存渲染，缓存不会跟着子节点的变化刷新。画框原先带阴影，导致画框里的描边框淡出、背景压暗全部失效，所以画框不加阴影；镜头快切用完的模糊滤镜也要立刻清掉。
- 抽出：推镜结束后，把截图里的关键区域裁成一张卡片浮起、放大、带阴影，背景压暗，一道高光扫过（`Extract` / `lift`）。画布段抽的是价格卡，搜索段是 3 个原始出处，同步段是 iCloud 卡。
- 记忆段：文件树和文件内容逐行滑入，再逐字打出新条目。
- 结尾：图标旋转放大，KANSOKU 逐字母升起，下划线从中间向两边画出。

## 素材采集

- 已采集（2026-09-26，2880×1800）：`new-canvas.png`、`new-search.png` 来自开发版 `pnpm dev:desktop`；`new-sync.png` 来自正式版 0.43.4（开发版没有 iCloud 权限，显示「异常」）。
- 更新菜单不拍：原生菜单截不到，而且正式版的更新通道上最新版本还是 0.43.4，标题栏的更新按钮不会出现。「升级只下差异」只放在 Pill 里。
- 记忆不拍真图：个股页 AI 点评带真实持仓，记忆文件里是真实的交易纪律原话。改用代码画动画。
- 搜索用的是 codex 后端（拍完已关掉），回答里照样列出了原始出处链接，所以文案保留「回原始出处查」。
- 画布那张需要真跑一轮 AI 对话生成画布，会花一点 token。标的用公开大盘股（比如 NVDA.US），不用持仓相关的问题。
- 截图红线：不出现真实持仓、账户金额、本地 AI 费用、API key、iCloud 账户名。每张截图入库前先给用户过目。
- 画布只用静态截图加镜头推移，不录屏。以后要让 K 线真动起来，再补一段 4 秒录屏，用 Revideo 的 `Video` 节点替换。

## 验收标准

1. 总时长 55 ± 3 秒（改版后 55.3 秒）；ffprobe 确认 1920×1080 / 30fps / H.264 / AAC 双声道。
2. 每个节拍中点抽一帧检查：同屏叠加文字不超过两层，没有叠字、没有截断、叠加元素不压住 App 自己的文字。
3. 静音也能看懂：逐帧确认每句主句完整停留至少 2.5 秒。
4. 定位红线：全片不承诺收益，不出现「自动交易」一类说法。
5. 旧片 `pnpm video:render` 渲染结果不变；新成片继续被 `apps/video/.gitignore` 忽略。
6. `pnpm --filter @kansoku/video typecheck` 通过。
